# Changelog

## 1.0.0 — 2026-10-15

Initial public release of **Joint-240 SBS Disagreement and One-Step
Counterfactual Action Outcomes**.

### Contents

* 8,886 retained labeled state-context records
* 21,854 retained alternative-action outcome records
* 236 represented scenarios from 240 original independently seeded scenarios
* 6 policy metadata rows
* Public documentation: README, SCHEMA, PROVENANCE, LIMITATIONS, USAGE,
  CITATION, ATTRIBUTION, overlap declaration, validation script, checksums

### Exclusions

* 98 historically ambiguous state keys (including 2 labeled states and 4
  linked terminal rows)
* Already-public SBS reference utilities and 260 public learnability aggregates
* Public-equivalent alternative outcomes, dense legacy records, fitted
  predictions, raw shards, third-party traces, and private provenance paths

### Scope

Historical exploratory synthetic-simulator dataset. Not the Performance
Evaluation manuscript’s production-derived confirmatory evidence.
Publication destinations: GitHub source tree, Zenodo dataset record with DOI,
and an identical Hugging Face mirror.

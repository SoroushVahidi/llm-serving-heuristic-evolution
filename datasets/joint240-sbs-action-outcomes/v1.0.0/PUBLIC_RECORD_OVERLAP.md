# Public-record overlap declaration

The Phase 6B audit compared identity and numeric values against named public
GitHub and Zenodo artifacts. It found:

* 260 exact public learnability aggregate rows
* 8,888 SBS reference utilities equal to the public scenario-level utility
  matrix
* two alternative outcomes scientifically equivalent to the earlier public
  terminal-criticality table

All of those are excluded from this release.

Additionally, 98 scan keys with all 95 numeric features equal to earlier
Alive-acquired states are unresolved at full hidden-state identity. Their two
labeled states and four terminal rows are excluded.

This release therefore declares:

* `state_context.csv`: 8,886 retained labeled states; no unresolved keys
* `alternative_action_outcomes.csv`: 21,854 retained alternatives; no public
  reference rows, public aggregate rows, or unresolved-state rows
* no 453,016-state observation frame is redistributed

The bounded check covers named project artifacts. It is not a proof of
absence from every possible third-party mirror.

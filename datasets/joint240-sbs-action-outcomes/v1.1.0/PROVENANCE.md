# Scientific provenance and limits

This is a filtered view of the completed `joint240_sbs_disagreement_scan_v1/full_v1` campaign, not a new run. The frozen 453,016-row source scan SHA-256 is in `metadata/provenance.json`; the 452,918-row public table is generated by excluding 98 keys that match earlier Alive-acquired records on all 95 numeric physical-state features within absolute tolerance `1e-12`. Hidden simulator identity is unavailable for those keys, so they are omitted conservatively. The retained 8,886 disagreement states match the v1.0.0 selected-state count; 444,032 retained equal-action states supply the newly accessible full-trajectory context.

Phase 6B independently validated the canonical scan's unique state/scenario-step keys, all 240 scenario and five-fold coverage, five policy comparisons per state, frozen source hashes, feature validity and relation to the selected terminal labels. The original scan source was preserved in the Joint-240 local provenance archive and verified in Wulver project backup. This compact public table is not a disaster-recovery copy of the full source tree.

The scan uses synthetic requests generated from seeded NumPy draws and fixed scenario settings. It does not import raw upstream traces or user prompts. The scientific question is whole-policy action disagreement and SBS continuation opportunity. It contains no module-transplant result, configuration, or benchmark contribution.

Results are exploratory and state observations are correlated within scenarios. An action difference identifies an opportunity to study an alternative, not an assured utility gain. The historical selected-state v1.0.0 release shows a confidence interval crossing zero for the learned override estimate and should be read alongside this extension.

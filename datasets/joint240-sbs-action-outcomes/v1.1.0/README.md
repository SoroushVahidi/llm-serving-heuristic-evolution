# Joint-240 SBS Action Outcomes — Full State Scan Extension (v1.1.0)

**Creator:** Soroush Vahidi. **Version:** 1.1.0 (2026). This is a versioned extension of [Joint-240 SBS Action Outcomes v1.0.0](https://zenodo.org/records/23398347), not a new experimental campaign. The v1.0.0 release provides 8,886 selected disagreement contexts and 21,854 terminal alternative-action outcomes. This extension adds the broader SBS predecision scan: **452,918 state records** across **240 independently seeded synthetic scenarios** and five fixed folds. It conservatively excludes 98 states whose 95 physical features match prior public Alive-acquired records. Of the released states, 8,886 are selected disagreement states already represented in v1.0.0; **444,032 equal-action state records add new action-opportunity context**. States within a scenario are dependent; 240 scenarios, not 452,918 rows, are the sampling units.

## What this enables

The full scan measures when six P6 whole-scheduler policies would choose the same or different immediate action along a fixed SBS (`kv_constrained_online`) trajectory. At each predecision state the five other policies were queried on copied observable state; **only SBS was executed**. The scan records 95 numeric predecision state features, six canonical actions and policy-disagreement indicators. Equal-action states have no executed alternative terminal branch; do not infer terminal benefit for them. The selected alternative terminal outcomes remain in v1.0.0. The study does not demonstrate a deployed or closed-loop learned scheduler improvement.

`data/full_sbs_state_scan.csv.gz` is the 127-column UTF-8 CSV. `metadata/scenario_manifest.csv` describes all 240 generated scenarios, `metadata/split_oof_folds.csv` records fixed folds, and `metadata/policy_metadata.csv` repeats the small already-public policy dictionary for standalone loading. `metadata/excluded_98_matched_feature_states.tsv` identifies the conservative exclusions. See `SCHEMA.md`, `PROVENANCE.md`, `RIGHTS_AND_ATTRIBUTION.md`, and `validation/validate_public.py`. Run `python3 validation/validate_public.py` and `sha256sum -c CHECKSUMS.sha256` from this directory. A representative load is `pandas.read_csv("data/full_sbs_state_scan.csv.gz",compression="gzip",nrows=5)`.

The original scan source, shards, generator, manifests and prior private validation remain preserved; this compact release is not a backup of that full tree. The source scan SHA-256 and exclusion method are in `metadata/provenance.json`. No new simulation was performed for this version.

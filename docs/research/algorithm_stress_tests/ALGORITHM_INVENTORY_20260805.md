# Algorithm Stress-Test Library — Algorithm Inventory (2026-08-05)

Complete inventory of scheduling algorithms/policy families in scope for
the stress-test library. Three sections, per the task's own structure:
internal/foundational policies, integrated external baselines, planned
core external baselines (spec-only — no implementation work here).

All "observable inputs" are drawn from `ObservableRequest`/`ObservableState`
(`src/llmserveopt/core/types.py`) unless noted; all internal policies
correctly avoid `Request.actual_output_tokens` (hidden from `BasePolicy`
by construction), so "no leakage" is structural, not a per-policy claim
that needs re-verifying each time.

## Notes on scope discipline

- Entries 15/17/18 above have EXISTING internal faithful-reimplementation
  code that predates this task (confirmed via `git log`) — using them as
  stress-test SUBJECTS (running existing code against new workloads) is
  not "beginning implementation of Sarathi-Serve/Llumnix/DistServe," which
  this task is explicitly told not to do. This task adds no new lines to
  any of `sarathi_faithful.py`, `llumnix_faithful.py`,
  `distserve_faithful.py`, or their shared `KVBlockSpaceManager`.
- Entry 16 (Apt-Serve) has zero existing code and was not locatable with
  confidence in the literature pass (see the literature-search document) —
  its catalog entries are specification-only, matching the task's explicit
  allowance ("create catalog/specification entries even if the current
  simulator cannot yet execute them").
- Entry 14 (VTC) is included here for completeness/cross-reference only;
  per the exclusion list, no VTC files are touched by this task, and no
  VTC-targeted stress-test workloads are added under this task's own
  directories (VTC already has its own dedicated, separately-validated
  fairness-extension workloads).
- HyGen and ATHENA-Serve were confirmed (in the VTC audit pass) to have no
  matches anywhere in this repo's docs or policy code; not carried forward
  into this inventory as they are neither implemented nor previously
  researched — a literature pass on them would be starting fresh research
  outside this task's core algorithm set, deferred.

# JOINT240 SBS Disagreement Scan v1

Status: preregistered read/compute-only diagnostic.

## Purpose

Measure action opportunity under the actual SBS trajectory distribution:

```text
d_SBS = trajectories generated by fixed kv_constrained_online.
```

At every SBS predecision state, independently query all six P6 policies and
measure whether any non-SBS policy proposes a genuinely different action.

This task measures only `ACTION_OPPORTUNITY`. It does not measure terminal
causal effects or beneficial overrides.

## Primary Semantics

For each frozen joint240 scenario:

1. instantiate the normal simulator from the frozen scenario definition;
2. execute fixed `kv_constrained_online` end-to-end;
3. before each SBS action is applied, deep-copy the observable state and query
   all six P6 native policies;
4. canonicalize full actions, including non-admit fields and prefill chunk
   overrides;
5. record action support and online-safe state/action-diff features;
6. execute only SBS on the real trajectory.

Shadow policies must never mutate the SBS trajectory. No terminal
fork-to-completion counterfactuals are allowed in this diagnostic.

## Features

Reuse:

- `LIVE_STATE_FEATURES_V1` without trajectory-control fields: 95 core physical
  state features.
- `ACTION_DIFF_FEATURES_V1`: candidate-vs-SBS differences for the five non-SBS
  alternatives.

Forbidden:

- actual future output length;
- terminal utility;
- post-decision outcomes;
- learned model predictions or tuned thresholds.

## Outputs

The scanner writes:

- `state_rows.shard*.csv`: one row per SBS decision state;
- `policy_rows.shard*.csv`: one row per non-SBS candidate policy per state;
- `per_scenario_support.csv`;
- `per_fold_support.csv`;
- `manifest_all_disagreements.csv`;
- `manifest_episode_thinned.csv`;
- `manifest_all_equal_controls.csv`;
- `summary.json` after aggregation.

## Episode Thinning

`MANIFEST_ALL_DISAGREEMENTS` contains every SBS state where at least one
non-SBS P6 policy differs from SBS.

`MANIFEST_EPISODE_THINNED` is outcome-blind: within each contiguous
disagreement episode in a scenario, retain the first disagreement state and
every 10th subsequent disagreement state.

Controls are deterministic SHA256-sampled all-equal states at
`ceil(0.10 * n_disagreement_states)`.

## Interpretation

Possible interpretations:

- `OLD_ACQUISITION_WAS_PRIMARY_BOTTLENECK`: d_SBS has broad P6-vs-SBS action
  support that old Alive-oriented acquisition missed.
- `P6_ACTION_LIBRARY_IS_PRIMARY_BOTTLENECK`: exhaustive d_SBS trajectories
  almost always produce identical P6 actions.
- `MIXED_ACTION_SUPPORT`: opportunities exist but are concentrated by
  policy/scenario/episode.
- `SCAN_PENDING`: full scan is not complete.

## D. Cited Only as Related Work

They are not reproduced as external baselines unless explicitly stated otherwise.

## E. Project-Generated Synthetic Data

The main portfolio experiments use project-generated synthetic workloads:

- controlled Family A/B/C scenarios;
- unified 176-scenario x 6-policy utility matrix;
- joint multi-mechanism 240-scenario workload;
- portfolio typed-GP TRAIN screen scenarios;
- real-vLLM request manifests generated by this project for Qwen2.5-0.5B.

These should be described as synthetic/project-generated workloads, not as external datasets.

## Hugging Face Account Audit

Public datasets observed under `SoroushVahidi` include:

- `SoroushVahidi/llm-serving-scheduler-baselines`
- `SoroushVahidi/llm-serving-selector-regret`
- `SoroushVahidi/module-intervention-credit`
- several unrelated optimization, allocation, ranking, and sample datasets.

Relevant observations:

- `llm-serving-scheduler-baselines` is public and contains earlier scheduler-baseline artifacts, including configs such as `per_policy_results` and `tracelab_scheduler_ood_policy_sweep`. It is related to prior project work but is not the exact final manuscript artifact set.
- `llm-serving-selector-regret` is public and contains earlier selector/regret artifacts. It is related but not the exact final paper evidence release.
- `module-intervention-credit` is public and records earlier module-credit/AutoML artifacts. It is not used directly in this manuscript.

Conclusion: no existing Hugging Face dataset should be cited in the manuscript as the canonical final-paper data artifact. A dedicated future release such as `SoroushVahidi/llm-serving-scheduler-portfolio-results` would improve reproducibility, but it was not created in this task.

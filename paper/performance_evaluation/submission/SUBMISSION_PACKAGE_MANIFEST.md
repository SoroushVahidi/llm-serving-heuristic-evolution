# Submission Package Manifest

This package contains the files necessary for submission to Performance Evaluation.

- `main.tex`: The LaTeX source code for the manuscript.
- `main.bbl`: The built bibliography file.
- `references.bib`: The BibTeX file.
- `figures/`: The folder containing all vector graphic figures.
- `performance_evaluation_highlights.txt`: The 3-5 bullet points highlights file.
- `cover_letter.txt`: The submission cover letter.
- `suggested_reviewers.md`: A list of suggested reviewers (if requested by the portal).
- `SUBMISSION_CHECKLIST.md`: The status of all submission requirements.

*(Note: The canonical human-facing PDF is tracked at the root level under paper/when_does_llm_serving_scheduler_adaptation_matter.pdf; compile intermediates inside this folder are ignored.)*

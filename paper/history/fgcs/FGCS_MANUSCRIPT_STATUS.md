# FGCS Manuscript Status

This directory originated with the withdrawn LLM 2026 submission. Its name is
retained intentionally for Git history, existing references, and reproducible
build paths.

The current [`main.tex`](main.tex) is the canonical FGCS journal manuscript.
The current compiled PDF is [`main.pdf`](main.pdf). The figure source is
[`scripts/plot_fgcs_figures.py`](scripts/plot_fgcs_figures.py), and the build
record is [`experiments/FGCS_MANUSCRIPT_BUILD_V1.json`](../../experiments/FGCS_MANUSCRIPT_BUILD_V1.json).

The historical submission archive and `submission_package/` are retained for
provenance. They must not be treated as the current FGCS submission package.
See [`FGCS_SUBMISSION_PACKAGE_MANIFEST_V1.md`](FGCS_SUBMISSION_PACKAGE_MANIFEST_V1.md)
for the current package inventory.

## Current figures

The manuscript references `fgcs_pipeline`, `fgcs_disagreement_rates`,
`fgcs_pressure_transition`, `fgcs_fresh_headroom`, and `fgcs_regime_map`.
They are generated by `scripts/plot_fgcs_figures.py`. Other figures and plotting
scripts in this directory are historical and remain preserved.

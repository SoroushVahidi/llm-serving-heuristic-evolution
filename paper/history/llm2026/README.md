# Historical LLM 2026 Manuscript Material

This directory contains the historical manuscript "The Exploitability Gap in LLM-Serving Scheduler Portfolios" which was submitted to LLM 2026, accepted, but withdrawn before publication.

This material has been superseded by the "Performance Evaluation" journal manuscript ("When Does LLM-Serving Scheduler Adaptation Matter? Action Opportunity and Causal Headroom in Production-Derived Replay").

It is retained here solely for historical provenance. The historical paper is closely related to the current paper, representing an earlier evolutionary stage of the research.
